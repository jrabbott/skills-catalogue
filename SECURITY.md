# Security Policy

## Supported versions

This repository is a private skills catalogue. Security fixes are applied on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Prefer one of these channels:

1. **GitHub private vulnerability reporting** — use *Security* → *Report a vulnerability* on this repository if enabled.
2. **Private contact** — open a private discussion with the repository owner ([@jrabbott](https://github.com/jrabbott)) via a channel you already use for this project.

Include as much detail as you can: affected skill or path, steps to reproduce, and impact.

## What to expect

Reports are reviewed as soon as practical. You can expect an acknowledgment when the report is received, and a follow-up when the issue is confirmed or closed. Do not share exploit details publicly until a fix is available.
