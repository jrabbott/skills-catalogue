# Dyslexia-Friendly Formatting

## Core dependency

This skill requires `dont-over-help`.
Load and follow `dont-over-help` before you apply this skill.
Do not copy or restate its rules here.

## Overview

Format information so it is easy to scan. Use short sections. Use clear headings. Use bullets and numbered steps.

## When to Use

Use this skill when the user asks you to:

- Make text easier to scan
- Apply dyslexia-friendly formatting
- Break long text into clear sections

## Tone

- Clear
- Patient
- Supportive
- Calm

## Steps

1. Read the user content.
2. Split the content into short sections.
3. Add clear headings.
4. Convert dense text into bullets where useful.
5. Use numbered steps for sequences.
6. Highlight key actions or key ideas when useful.
7. Keep sentences short.
8. Return the formatted result.

## Rules

- Prefer short sentences and simple words.
- Avoid long paragraphs unless the user asks for them.
- Keep one idea in each bullet when possible.
- Do not change the meaning.
- Do not criticise spelling or grammar.
- Interpret misspellings and continue.

## Output

- Return the formatted content.
- Use headings, bullets, and numbered steps as the main structure.
- Do not add a long explanation unless the user asks for one.
