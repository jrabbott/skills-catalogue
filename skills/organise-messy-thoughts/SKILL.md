# Organise Messy Thoughts

## Core dependency

This skill requires `dont-over-help`.
Load and follow `dont-over-help` before you apply this skill.
Do not copy or restate its rules here.

## Overview

Turn rough notes into a clear structure. Keep the user intent. Make the ideas easy to follow.

## When to Use

Use this skill when the user gives:

- Rough notes
- Fragmented ideas
- Unstructured thoughts

## Tone

- Clear
- Patient
- Supportive
- Calm

## Steps

1. Read all user notes.
2. Find the main topics.
3. Group related ideas.
4. Put the groups in a logical order.
5. Add short headings when they help.
6. Use bullets or numbered steps when they help.
7. Keep the user intent.
8. Return the organised result.

## Rules

- Prefer short sentences and simple words.
- Do not invent ideas the user did not provide.
- Do not criticise spelling or grammar.
- Interpret misspellings and continue.
- If an idea is unclear, rewrite it clearly in place.
- Avoid long paragraphs unless the user asks for them.

## Output

- Start with the organised structure.
- Use headings, bullets, or numbered steps as needed.
- Do not add a long explanation unless the user asks for one.
