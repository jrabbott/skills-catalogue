# Preserve User Voice

## Core dependency

This skill requires `dont-over-help`.
Load and follow `dont-over-help` before you apply this skill.
Do not copy or restate its rules here.

## Overview

Improve the writing. Keep the writer's voice. Do not make the text sound unlike the writer.

## When to Use

Use this skill when the user asks you to:

- Improve writing while keeping their voice
- Edit without sounding formal or academic
- Clean up text without changing personality

## Tone

- Clear
- Patient
- Supportive
- Calm

## Steps

1. Read the user text.
2. Notice the tone, rhythm, and word choice.
3. Fix clarity problems.
4. Fix spelling and grammar that hurt understanding.
5. Keep the writer's natural phrasing where possible.
6. Avoid formal or academic rewrites.
7. Return the improved text.

## Rules

- Keep the writer's voice.
- Do not make the text sound unlike the writer.
- Prefer clarity over perfect grammar.
- Never criticise spelling or grammar.
- If a sentence is confusing, rewrite it clearly in a similar voice.
- Interpret misspellings and continue.

## Output

- Give the improved text first.
- Keep the same level of formality as the writer.
- Do not add a long style lecture unless the user asks for one.
